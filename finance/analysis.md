# 财务分析与估值模型

好商业模式最终需要反映在真金白银的财务报表中。本页整理财务分析的核心脉络与估值工具。

---

## 三大财务报表核心关注点

### 1. 资产负债表（看家底与风险）
- **资产结构**：轻资产模式还是重资产模式？固定资产/总资产比例如何？
- **负债与偿债风险**：有息负债率、现金短债比、流动比率。
- **营运质量**：应收账款周转天数、存货周转天数（警惕应收账款异动与存货减值暴雷）。

### 2. 利润表（看赚钱能力）
- **毛利率与净利率**：高毛利代表定价权与护城河，关注毛利率是否常年保持稳定或提升。
- **期间费用率**：销售费用率、研发费用率、管理费用率是否可控，是否存在规模效应（费用率随规模扩大而摊薄）。
- **扣非净利润**：剔除政府补助、投资收益等非经常性损益，看主业真实盈利水平。

### 3. 现金流量表（看真假与成色 —— 最关键）
- **经营活动现金流净额**：净利润是否有真金白银的现金流入？（经营现金流净额 / 净利润 理想应 > 1）。
- **资本开支（CAPEX）与自由现金流（FCF）**：
  $$\text{自由现金流} = \text{经营现金流} - \text{资本性支出}$$
  能持续产生充沛自由现金流的企业才具备真正的造血能力与持续分红/回购能力。

## 杜邦分析体系（拆解 ROE）

$$\text{ROE（净资产收益率）} = \text{销售净利率} \times \text{总资产周转率} \times \text{权益乘数}$$

- **净利润率驱动（高暴利模式）**：如高端白酒、奢侈品、创新药（靠品牌和壁垒）。
- **资产周转率驱动（高周转模式）**：如连锁超市、快消品（薄利多销，极致运营效率）。
- **权益乘数驱动（高杠杆模式）**：如银行、房地产（靠资金杠杆撬动收益，抗风险能力弱）。

## 常用估值指标适用场景

| 指标 | 全称 | 适用行业与特征 | 局限性 |
| :--- | :--- | :--- | :--- |
| **PE (市盈率)** | 市值 / 净利润 | 盈利稳定的消费、公用事业、成熟制造 | 不适用于周期股和亏损成长股 |
| **PB (市净率)** | 市值 / 净资产 | 重资产周期股（钢铁/水泥）、金融（银行/券商） | 轻资产公司（互联网/软件）PB 偏高，参考意义弱 |
| **PS (市销率)** | 市值 / 营业收入 | 高成长期但尚未盈利的 SaaS、科技、生物医药 | 无法反映成本控制和真实盈利能力 |
| **股息率 (Dividend Yield)** | 每股分红 / 股价 | 红利低波、高现金流成熟公用事业公司 | 需结合分红持续性与分红比例（Payout Ratio）分析 |
